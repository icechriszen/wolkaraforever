# WolkaraForever guide

> Reviewed: 2026-11-24 · Source behavior: `0a38398`

Use this guide to install this CN/iPhone fork and manage a Forever installation.
Start with the [简体中文指南](../README.zh-CN.md) for Chinese setup and controls.
The [fork overview](../README.md) describes the integrated `main` branch and validation scope.

1. [Install WolkaraForever](INSTALLATION.md) to prepare your Mac and device, build the app, and start it for the first time.
2. [Build and run WolkaraForever](BUILDING.md) to see how a build is assembled, which execution
   modes a build offers, and how to run, package, and verify it.
3. [Use WolkaraForever](USING_WOLKARAFOREVER.md) to download a game, choose languages, configure
   controls and voice, manage add-ons, and recover your interface.
4. [What every control does](UI_REFERENCE.md) for a reference row by row, with a picture of every
   page and sheet.
5. [Use WolkaraForever on iPhone](IPHONE.md) for phone-specific setup and limits.
6. [Install the unsigned External JIT app](SIDELOADING.md) when you are sideloading
   `wolkaraforever-unsigned.ipa` instead of building the app.
7. [Send us a log](SENDING_LOGS.md) when something goes wrong — a few taps on the iPad, and no
   computer needed.

For fork-specific reports, use [this fork’s issues](https://github.com/icechriszen/wolkaraforever/issues).
For help, read [Compatibility](../COMPATIBILITY.md) and send the log described in
[Send us a log](SENDING_LOGS.md). Never share credentials, signing material, pairing records,
account information, or device identifiers.
